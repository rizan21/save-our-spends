# Components

## Overview
Central UI component catalog for Spread-Spends, organizing common design primitives, authentication views, group navigation, PWA offline capabilities, and modular backward-compatible re-export stubs.

## Subdirectories & Boundaries
- [Auth](./auth/README.md): Google sign-in onboarding and user profile editing modals.
- [Common](./common/README.md): Design system primitives (buttons, modals, navbar, avatar, theme toggle, error boundary).
- [Export](./export/README.md): Direct external links to Google Drive spreadsheets.
- [Groups](./groups/README.md): Group listings, tab navigation headers, and swipeable tab containers.
- [Members](./members/README.md): Member invitation and approval re-exports.
- [PWA](./pwa/README.md): Installation dialogs and network status indicators.
- [Settlements](./settlements/README.md): Debt simplification and payment modal re-exports.
- [Transactions](./transactions/README.md): Expense creation, transaction item, and history timeline re-exports.
