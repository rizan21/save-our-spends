# Legal Pages

## Overview
Provides public in-app legal views for **Save Our Spends** required for Google OAuth consent screen verification and user transparency.

## Components
- [`PrivacyPolicyPage.tsx`](./PrivacyPolicyPage.tsx): Comprehensive client-side privacy policy disclosing scope usage (`drive.file`, `userinfo.profile`, `userinfo.email`), zero-server architecture, anti-misuse guarantees, and the mandatory Google API Limited Use disclosure.
- [`TermsOfServicePage.tsx`](./TermsOfServicePage.tsx): Open-source service terms, disclaimer of financial/banking services, and warranty disclaimers under the MIT License.
