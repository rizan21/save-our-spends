# Pages

## Overview
Root pages container grouping top-level application views: group selection/creation (`groups`) and individual group workspace details (`group`).

## Subdirectories & Boundaries
- [Groups](./groups/README.md): Groups listing, group card dashboard, creation modal, and spreadsheet import dialog.
- [Group Detail](./group/README.md): Group workspace container coordinating tabs for overview, expenses, balances, settlement, and members.
- [Legal](./legal/README.md): In-app public legal views for Privacy Policy and Terms of Service.
